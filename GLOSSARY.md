# Glossary

- **same-name override**: Calling `pi.registerTool` with a tracked built-in tool name (`bash`, `eval`, `grep`, or `glob`), copying its live description, parameters, and available prompt guidelines at `session_start`, preserving its native label, load mode, strictness, and approval policy (including `grep`'s dynamic read tier), and delegating execution directly to the native built-in via `ctx.invokeTool` while customizing ANSI TUI rendering.
- **turn group**: All `bash`, `eval`, `grep`, and `glob` tool calls occurring after the latest `role: "user"` message entry (or live `before_agent_start` boundary) and before the next user prompt. Internal agent-loop turns and intervening untracked tools do not split the group; each tracked invocation contributes one count and shares a chronological call index across all four tools.
- **summary line**: The single-line, theme-styled ANSI TUI component owned by the first tracked call of any name in a **turn group** when collapsed. It dynamically reflects the group's invocation counts in fixed `bash` → `eval` → `grep` → `glob` clause order, omitting zero counts; later tracked calls and all collapsed partial/final results emit no ordinary text rows. Expanded view delegates to each call's native result renderer.
- **branch fallback**: Rebuilding **turn group** memberships, chronological call indices, and all four tool counts from `ctx.sessionManager.getBranch()` at `session_start`, `message_end`, and read-only `tool_result` observation. Persisted `toolCall.arguments` object references key a `WeakMap<object, TurnGroupSummary>` so resumed or replayed sessions render the same **summary line** without live `tool_call` events and reconcile with live groups without double-counting.
