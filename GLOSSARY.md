# Glossary

- **same-name override**: Calling `pi.registerTool` with a tracked built-in tool name (`bash`, `eval`, `grep`, or `glob`), copying its live description, parameters, and available prompt guidelines at `session_start`, preserving its native label, load mode, strictness, and approval policy (including `grep`'s dynamic read tier), and delegating execution directly to the native built-in via `ctx.invokeTool` while customizing ANSI TUI rendering.
- **turn group**: A contiguous chronological run of tracked `bash`, `eval`, `grep`, and `glob` tool calls bounded by a user prompt (`role: "user"` entry or live `before_agent_start`), non-empty assistant prose (`type: "text"` with non-whitespace text, whether across internal turns or interleaved between tool calls inside one assistant message), or an untracked tool call (such as `read`, `edit`, `write`, or `task`). Internal agent-loop turns (`turn_start`), `thinking` blocks, and empty/whitespace-only text blocks keep the group intact; each tracked invocation contributes one count and shares a 0-based chronological call index within its group.
- **summary line**: The single-line, theme-styled ANSI TUI component owned by the first tracked call of any name in a **turn group** when collapsed. It dynamically reflects the group's invocation counts in fixed `bash` → `eval` → `grep` → `glob` clause order, omitting zero counts; later tracked calls and all collapsed partial/final results emit no ordinary text rows. Expanded view delegates to each call's native result renderer.
- **branch fallback**: Rebuilding **turn group** memberships, chronological call indices, and all four tool counts from `ctx.sessionManager.getBranch()` at `session_start`, `message_end`, and read-only `tool_result` observation. Partition history at user messages, non-empty assistant `text` blocks, and untracked `toolCall` blocks in exact chronological content-block order. Persisted `toolCall.arguments` object references key a `WeakMap<object, TurnGroupSummary>` so resumed or replayed sessions render the same **summary line** without live `tool_call` events. Reconcile with active and completed live groups without double-counting or regressing completed groups when a lagging branch snapshot is observed, while adopting fuller persisted group totals.
